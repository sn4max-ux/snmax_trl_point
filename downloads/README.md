# Hattrick — с чего начать

Hattrick — индикатор для MetaTrader 4, который следит за графиком и подсказывает момент,
когда совпали три условия для входа. Он не торгует сам и не даёт гарантированных сигналов
«покупай/продавай» — решение всегда за вами.

## Установка

1. Скопируйте `i_trl_avgline.ex4` (или `i_trl_avgline_en.ex4` для английской версии) в
   папку `MQL4\Indicators` вашего терминала MetaTrader 4.
2. Перезапустите терминал или обновите список индикаторов (правой кнопкой по
   «Индикаторы» → «Обновить»).
3. Перетащите индикатор на график любой валютной пары.
4. При первом прикреплении терминал спросит разрешение на импорт DLL — подтвердите
   (нужно для кнопок связи, которые открывают сайт в браузере).

## Цель — 1 доллар, не все деньги рынка

Обязательное условие всей системы: объём 0.01 лота — цель 1 USD за сигнал, независимо
от размера депозита. Депозит может быть любым; 10 USD — лишь пример минимально возможного
старта (в этом случае цель — 10% от депозита за сигнал). Не попытка выжать из рынка по
максимуму. Как только цель достигнута — на сегодня хватит. Погоня за «ещё немного» вместо
фиксации маленькой цели — то, из-за чего небольшие депозиты чаще всего сгорают.

## Что вы увидите на графике

- Линия **AVG_LINE** — зелёная вверх, красная вниз — направление.
- Штриховые линии канала сверху и снизу — границы, к которым должна дойти цена.
- Значение **RSI** внизу справа — меняет цвет у зон 30/70.
- Три кнопки внизу графика — «Позвонить», «Задать вопрос», «Как это работает» —
  открывают сайт продукта.

## Сигнал (Alert 3)

Индикатор оповещает, когда одновременно выполнены три условия:

1. AVG_LINE показывает направление (вверх/вниз).
2. Цена коснулась соответствующей границы канала.
3. RSI(14) в зоне перепроданности/перекупленности (ниже 30 / выше 70).

Сигнал — повод посмотреть на график, а не команда на вход. Полный порядок проверки
перед входом (шесть шагов «Сопровождение после сигнала») — на странице продукта:
https://sn4max-ux.github.io/snmax_trl_point/

## После входа

Индикатор сам не открывает и не закрывает позиции. Безубыток и закрытие по прибыли уже
открытой сделки — отдельный необязательный советник, либо делайте то же самое руками.

## Пробный период

14 дней. По истечении индикатор не удаляется — становится неактивным (график остаётся
видимым), кнопки связи продолжают работать.

## Важно

Цена может резко пойти против вас на новостях. Рынок иррационален. Торгуйте только теми
деньгами, потерю которых готовы принять. Цель — 1 доллар на 0.01 лота, а не все деньги
рынка.
